# 🧠 主力心態模擬預判系統 MMPS
> Market Maker Psychology Simulation System

台股主力操盤行為分析工具，透過少數可觀測訊號推算主力當前操盤週期與下一步概率。

---

## 📌 系統概述

MMPS 不是「預測股價」，而是從可觀測的訊號推算：
- 主力目前處於哪個操盤週期
- 下一步最可能採取的手法
- 散戶應如何對應

### 四維分析框架

| 維度 | 說明 |
|------|------|
| 🧠 金融心理 | 散戶情緒、籌碼集中度、從衆效應、認知偏差 |
| 📉 技術操作 | 吸貨/洗盤/拉抬/出貨指紋識別 |
| 🌐 宏觀環境 | 外資匯入、台幣匯率、大盤位置、題材週期 |
| ⚖️ 法規限制 | 大股東申報、融資機制、借券餘額、內線防範 |

---

## 🔄 主力四大週期

```
[吸貨期] → [洗盤期] → [拉抬期] → [出貨期]
    ↑_____________________________|
```

### 各週期識別指紋

**吸貨期**
- 特定分點反覆小量買入
- 股價低檔橫盤，量縮
- 散戶論壇冷清
- 投信穩定小量買超

**洗盤期**
- 快速連續下殺跌破均線
- 隔日快速 V 型反轉
- 分點集中度不降反升
- 法人賣超但為「假動作」

**拉抬期**
- 三大法人同向爆量買超
- 均線多頭排列確立
- 帶量突破整理區
- 散戶開始追進（過熱訊號）

**出貨期**
- 高檔爆量滯漲
- 每次創高後即回調
- 分點開始分散
- 量縮後反彈無力

## 📊 概率計算方式

最少 5 項輸入訊號即可運行：

| # | 訊號 | 查詢方式 |
|---|------|---------|
| 1 | 分點集中度變化 | 玩股網 / HiStock |
| 2 | 量比（今日 vs 5日均量）| 任何報價工具 |
| 3 | K線型態 | 技術圖 |
| 4 | 法人近 3 日動向 | 三大法人表 |
| 5 | 論壇情緒溫度 | PTT / 爆料同學會 |
| 6 | 大盤位置（可選）| 加權指數 |
| 7 | 股價相對高低點（可選）| 近 60 日位置 |

**概率公式**

```
P(下一狀態) = Σ(訊號權重 × 訊號強度) / 正規化因子
```

## 🖥️ 儀表板使用方式

1. 下載 `dashboard/` 內的 HTML 檔案
2. 直接在瀏覽器開啟（無需伺服器）
3. 點選時間軸各節點查看主力行為詳解
4. 手機瀏覽器亦完全支援

### 儀表板包含

- 📈 60 日股價走勢圖（主力週期標注）
- 🕐 主力行為時間軸（可互動展開）
- 📊 四大週期概率矩陣
- ▶ 下一步手法概率預判
- 🔍 7 項訊號輸入矩陣
- 🔲 四維分析（心理/技術/宏觀/法規）
- 🔑 法規雷達掃描
- 📌 操作建議與進出場參考
